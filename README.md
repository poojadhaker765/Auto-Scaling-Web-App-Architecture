4. Full Web Architecture (Advanced Project)
📌 Description

Designed and deployed a scalable web application using AWS CloudFormation, Auto Scaling, Load Balancer, VPC, and RDS.

🛠️ Services Used
AWS CloudFormation
EC2 Auto Scaling Group
Application Load Balancer
VPC (Public + Private Subnets)
RDS (MySQL/PostgreSQL)
IAM Roles
⚙️ Architecture Flow

User → Load Balancer → EC2 (Auto Scaling Group) → RDS Database
